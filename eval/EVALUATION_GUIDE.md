# AI 기본법 RAG 평가 지표

이 문서는 AI 기본법 QA 서비스의 검색(Retrieval)과 답변(Answer) 품질을 평가하기 위한 기준을 정의한다.

평가 대상은 동일한 Golden Test Set을 사용하여 다음 세 가지 검색 방법을 비교한다.

1. Dense Retrieval
2. Hybrid Retrieval: Dense + BM25 + RRF
3. Hybrid Retrieval + Reranking

모든 실험에서 질문, 청크 데이터, 임베딩 모델, `K` 값, 답변 생성 모델과 프롬프트를 동일하게 유지한다. 기본값은 `K=5`로 한다.

## 1. Golden Test Set 구성

각 평가 문항에는 최소한 다음 정보가 필요하다.

```json
{
  "id": "q001",
  "question": "고영향 인공지능이란 무엇인가요?",
  "gold_evidence": [
    {
      "article": "제2조",
      "paragraph": "",
      "item": "4"
    }
  ],
  "reference_answer": "고영향 인공지능은 사람의 생명, 신체의 안전 및 기본권에 중대한 영향을 미치거나 위험을 초래할 우려가 있는 인공지능시스템으로서 법에서 정한 영역에 활용되는 것을 말한다.",
  "answerable": true
}
```

`gold_evidence`는 질문에 직접 답하는 최소 근거를 기록한다. 조문 전체와 해당 조문의 항·호 청크가 같은 내용을 담더라도 하나의 법률 근거로 정규화한다.

예를 들어 제2조 전체 청크와 제2조제4호 청크가 함께 검색되어도 정답 근거를 두 개 찾은 것으로 계산하지 않는다.

## 2. Retrieval 평가

### 2.1 근거 일치 판정

검색 결과는 다음 조건을 모두 만족할 때 정답 근거로 판단한다.

- 조 번호가 Golden Set과 일치한다.
- Golden Set에 항·호가 지정되어 있으면 해당 항·호와 일치한다.
- 검색 청크의 실제 내용이 질문에 필요한 근거를 포함한다.

조 번호만 같고 다른 내용을 담은 청크는 정답으로 처리하지 않는다.

### 2.2 Hit@K

상위 `K`개 검색 결과에 정답 근거가 하나 이상 포함되어 있는지를 평가한다.

```text
Hit@K = 1, 상위 K개에 정답 근거가 하나 이상 있는 경우
Hit@K = 0, 그 외의 경우
```

전체 점수는 모든 질문의 Hit@K 평균이다.

```text
Mean Hit@K = 질문별 Hit@K 합 / 전체 질문 수
```

예시:

- 정답 근거 제2조가 3위에 검색됨: `Hit@5 = 1`
- 정답 근거가 6위에 검색됨: `Hit@5 = 0`

### 2.3 Recall@K

질문에 필요한 전체 정답 근거 중 상위 `K`개에서 검색한 근거의 비율이다.

```text
Recall@K = 상위 K개에서 찾은 고유 정답 근거 수 / 전체 고유 정답 근거 수
```

예시:

질문에 제33조와 제35조가 모두 필요할 때:

- 두 조문 모두 검색: `Recall@5 = 2/2 = 1.0`
- 제33조만 검색: `Recall@5 = 1/2 = 0.5`
- 둘 다 검색하지 못함: `Recall@5 = 0/2 = 0.0`

조문 전체 청크와 같은 조문의 항 청크가 동시에 검색되어도 같은 근거는 한 번만 센다.

### 2.4 MRR@K

첫 번째 정답 근거가 얼마나 높은 순위에 검색됐는지 평가한다.

```text
RR@K = 1 / 첫 번째 정답 근거의 순위
```

상위 `K`개에 정답 근거가 없으면 `0`이다. 전체 MRR@K는 질문별 RR@K의 평균이다.

| 첫 정답 순위 | RR |
|---:|---:|
| 1위 | 1.000 |
| 2위 | 0.500 |
| 3위 | 0.333 |
| 4위 | 0.250 |
| 5위 | 0.200 |
| 상위 5개에 없음 | 0.000 |

### 2.5 검색 시간

필수 품질 지표는 아니지만 방법 선택을 위해 함께 기록한다.

- 질문 임베딩 시작부터 최종 Top-K 결과 생성까지 측정한다.
- Qwen Reranker 최초 모델 다운로드·로딩 시간은 별도로 기록한다.
- 모델 로딩 후 반복 검색 시간도 따로 기록한다.

## 3. Answer 평가

답변 평가는 검색 결과를 Context로 사용해 생성한 최종 답변을 대상으로 한다.

### 3.1 정답성

| 점수 | 기준 |
|---:|---|
| 2 | Reference Answer의 핵심 내용을 정확히 설명한다. |
| 1 | 일부 핵심 내용은 맞지만 중요한 조건·범위·예외가 빠져 있다. |
| 0 | 핵심 내용이 틀리거나 질문에 답하지 못한다. |

### 3.2 관련성

| 점수 | 기준 |
|---:|---|
| 2 | 질문에 직접 답하고 불필요한 설명이 거의 없다. |
| 1 | 질문에 답하지만 관련성이 낮은 내용이 섞이거나 답변이 우회적이다. |
| 0 | 질문과 무관하거나 사실상 답하지 않는다. |

### 3.3 근거 충실성

| 점수 | 기준 |
|---:|---|
| 2 | 답변의 모든 핵심 주장을 검색된 법령 근거가 직접 뒷받침한다. |
| 1 | 대부분 뒷받침되지만 일부 주장이나 조건의 근거가 부족하다. |
| 0 | 주요 주장이 검색 근거로 뒷받침되지 않는다. |

조문 번호를 표시했더라도 해당 조문이 실제 주장을 지지하지 않으면 충실한 근거로 인정하지 않는다.

### 3.4 Hallucination 여부

| 값 | 기준 |
|---|---|
| 없음 | 검색 근거에 없는 법률 내용·의무·예외·수치·조문을 만들지 않았다. |
| 있음 | 검색 근거에 없는 내용을 사실처럼 추가하거나 조문을 잘못 인용했다. |

문서 밖 질문에서 근거가 부족하다고 답한 경우는 Hallucination이 아니다. 근거가 없는데도 구체적인 법률 답변을 생성하면 Hallucination으로 판정한다.

## 4. 평가 질문 구성 권장안

Golden Test Set은 한 종류의 질문에 편중되지 않도록 구성한다.

| 질문 유형 | 예시 | 기대 근거 |
|---|---|---|
| 목적 | 이 법의 목적은 무엇인가요? | 제1조 |
| 정의 | 고영향 인공지능이란 무엇인가요? | 제2조 관련 호 |
| 단일 의무 | 고영향 인공지능 확인 절차는 무엇인가요? | 제33조 |
| 복수 근거 | 확인 절차와 영향평가 의무는 무엇인가요? | 제33조, 제35조 |
| 조건·예외 | 이 법이 국외 행위에도 적용되나요? | 제4조 |
| 문서 밖 질문 | AI 기본법 위반 과징금의 최신 부과 사례는? | 답변 불가 처리 |

최소 15~20개 문항을 권장한다. 정의, 의무, 절차, 예외, 복수 조문, 문서 밖 질문을 포함한다.

## 5. 비교 실험표

Retrieval 결과는 다음 형식으로 정리한다.

| 방법 | Hit@5 | Recall@5 | MRR@5 | 평균 검색 시간 |
|---|---:|---:|---:|---:|
| Dense |  |  |  |  |
| Hybrid |  |  |  |  |
| Hybrid + Reranking |  |  |  |  |

Answer 결과는 다음 형식으로 정리한다.

| 방법 | 정답성 평균 | 관련성 평균 | 근거 충실성 평균 | Hallucination 발생률 |
|---|---:|---:|---:|---:|
| Dense |  |  |  |  |
| Hybrid |  |  |  |  |
| Hybrid + Reranking |  |  |  |  |

```text
Hallucination 발생률 = Hallucination이 발생한 답변 수 / 전체 답변 수
```

## 6. 최종 방법 선택 기준

다음 순서로 최종 검색 방법을 결정한다.

1. Hit@5와 Recall@5가 높은 방법을 우선한다.
2. 성능이 비슷하면 MRR@5가 높은 방법을 선택한다.
3. 검색 성능 차이가 작으면 검색 시간이 짧고 구성이 단순한 방법을 선택한다.
4. Reranking이 실제 정답 근거의 순위를 개선할 때만 최종 파이프라인에 포함한다.
5. 최종 답변에서 근거 충실성과 Hallucination 여부를 반드시 확인한다.

검색 지표가 좋아도 답변의 근거 충실성이 낮으면 최종 시스템이 개선된 것으로 판단하지 않는다.
